# frontend-template

Next.js App Router, Pixi.js, Tailwind CSS, Storybook, oxlint, and pnpm template.

## Requirements

Tool versions are pinned in `mise.toml`.

```bash
mise install
pnpm install
```

## Scripts

```bash
pnpm dev
pnpm storybook
pnpm lint
pnpm lint:fix
pnpm typecheck
pnpm build
pnpm build-storybook
```
